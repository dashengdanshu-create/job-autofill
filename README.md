# Job Autofill

Chrome 侧边栏插件，用保存在本机的求职档案填写招聘表单。支持多段教育、工作、实习、校园和项目经历，填写前可查看字段对应关系；不会自动提交申请。

## 安装

在本仓库 Releases 下载最新版扩展 ZIP，解压后打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。

也可以从源码构建（建议 Node.js 22）：

```sh
npm ci
npm run build
```

然后加载生成的 `dist` 文件夹。

## 使用

1. 打开插件，在“档案设置”填写并保存个人信息。
2. 打开招聘网站并登录，点击“检测表单”。
3. 检查字段、经历序号和匹配结果，再点击“填充”。
4. 在网页中补全需手动选择的内容，检查后自行保存或提交。

新增一段经历或页面重绘后，需要重新检测。条目按档案顺序对应；档案没有的内容不会补造。

## 适配范围

- 通用 HTML 表单，包含可访问的 iframe 和开放式 Shadow DOM 中的原生控件。
- 飞书招聘 `jobs.feishu.cn` 及其企业子域名：按标准字段路径、区块和经历序号识别，分别对应工作、实习、项目的同名“描述”字段。
- `jobs.gdjztech.com` 的北森表单：区分实习与工作区块，处理文本输入后的失焦提交。

学校、学历、地点等自定义下拉/联想控件，以及日期组件可能需要在网页手动选择。飞书适配目前验证了页面结构中的字段映射，未完成线上保存验证。企业自定义问题及后续页面结构变化可能需要新增适配。

## 个人信息与发布版

公开仓库与安装包不含真实用户档案、简历、导出的招聘页面、登录信息或个人调试记录。测试中的姓名、联系方式、经历和敏感字段样例是合成测试数据，不会加载成默认档案。

- 新安装的插件从空白档案开始。用户填写的档案保存在当前浏览器扩展的 `chrome.storage.local`，不会同步到 GitHub。
- 插件代码不主动发送网络请求，不使用 `chrome.storage.sync`。用户主动填写网页后，招聘网站可按其自身逻辑处理这些数据。
- 发布和更新源码不会清空原有本地档案。升级时请重新加载原扩展，不要卸载；换电脑或新装扩展时，可自行导出/导入档案。
- 导出的个人档案请保存在仓库以外。请勿把简历、真实页面、个人截图或登录信息提交到 issue。
- `.gitignore` 排除了常见本地导出、密钥、日志和构建目录；提交其他文件前仍需检查内容。

## 开发与验证

```sh
npm run verify    # 类型检查、构建、单元/DOM/隐私检查
npm run test:e2e  # 浏览器端测试，需先安装 Playwright Chromium
```

0.2.7 已通过 276 项单元/DOM/隐私测试、类型检查与构建。浏览器端整套测试尚未在当前发布环境完成。

平台规则位于 `src/adapters/`，新增适配后在 `src/adapters/index.ts` 注册，并添加去除个人信息的结构测试。不要将真实申请人的字段值或带个人标识的完整链接写入适配规则。
